# Apex Motorsport Hub

APEX is a 3-page Formula 1 website I built as part of the Stardance Challenge.

The idea was to create a website that makes exploring Formula 1 teams, drivers, race weekends, tyre strategy, and racing technology more interactive.

## Pages

### Home

The home page introduces APEX and highlights some of the main ideas behind Formula 1, including speed, engineering, strategy, and driver skill.

### Teams

The Teams page contains the 2026 F1 grid. You can filter the teams and explore the drivers and information shown for each team.

### The Race

The Race page explains parts of a race weekend, tyre strategy, DRS, ERS, aerodynamics, and different race strategies. It also includes interactive sections and an FAQ.

## Interactive Features

* Team filtering
* Race weekend timeline
* Tyre information cards
* Race strategy selector
* FAQ accordion
* Responsive navigation
* Links between all three pages

## Running the project

Clone the repository, install the dependencies, and start the development server:

```bash
npm install
npm run dev
```

The project can then be opened in a local browser.
