# Apex Motorsport Hub

Create a premium, competition-ready 3-page Formula 1 website called APEX — The World of Formula 1.

The website is being created for a 90-minute web development competition, so prioritize visual quality, polish, usability, working interactions, and a clean implementation over unnecessary technical complexity.

CORE REQUIREMENTS

Create exactly 3 main pages:

Home

Teams

The Race

The three pages must feel like one cohesive premium motorsport website.

Use a dark, cinematic, high-performance motorsport aesthetic with strong typography, excellent spacing, subtle gradients, glass effects, smooth animations and tasteful motion.

Do NOT copy the official Formula 1 website design. Create an original APEX identity inspired by modern motorsport, technology and editorial websites.

Use HTML/CSS/JavaScript or an appropriate modern frontend stack.

No backend or database is required.

Everything must work:

Navigation

Buttons

Filters

Accordions

Animations

Links between pages

Responsive layout

Do not leave placeholder text such as "Lorem ipsum", "Team Name", "Driver Name", etc.
